# Model attempts

Each folder holds the `fillbook/` package and tests that a model left behind.
Each model worked in a fresh copy of `starter/` with `TASK.md` and was told not
to look at `grader/` or `solutions/`. That rule was an instruction, not a
sandbox.

as tag `v2`; version 1 was replaced before the first commit. Don't regrade older
attempts against version 3: they never saw its task.
